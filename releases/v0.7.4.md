Harden descriptor import and SCTP integer boundaries

- Pin FileListener's source file during descriptor duplication, preventing
  concurrent Close from importing a recycled descriptor. Keep source and
  duplicated listener ownership independent. (#19)
- Reject invalid example bind addresses before opening a listener, including
  mixed valid/invalid address lists. (#20)
- Reject SetInitMsg arguments outside 0..65535 without changing kernel options.
  Preserve zero/default values and unsupported-target errors. (#21)
- Keep requested example buffer settings separate from kernel readbacks, so
  successive clients retain the same configuration. (#22)
- Reject association IDs that cannot fit the signed 32-bit Linux ABI before
  address queries or PeelOff can target a different live association. (#23)
- Replace duplicated blocking one-to-many test setup with bounded non-blocking
  setup verified through peer payload and metadata. Add SIGURG regressions;
  retain the public raw SCTPConnect errno behavior. (#24)
- Make each CI fuzz target complete one million executions with a separate
  failure timeout, avoiding duration-shutdown deadline false failures without
  retries or ignoring errors. Exercise release publication policy offline and
  allow an edited, still-untagged candidate to proceed after validation failure;
  existing release tags remain immutable.
- Remove shared fixed listen ports from notification, RawConn and listener
  fixtures, explicitly accept/clean up peer sockets, and verify the tests while
  legacy ports are occupied. (#29)

Before/after regressions cover each defect, including source-file Close races,
descriptor reuse and ownership, per-field INITMSG bounds, wide association IDs,
three successive example clients, invalid bind inputs, and interrupted setup.

Linux with kernel SCTP remains the supported platform, excluding Linux/386.
The minimum Go version remains 1.26; public signatures and dependencies are
unchanged. Invalid integer arguments that previously wrapped now return EINVAL
on supported live sockets. Standard deadlines, DialContext and additional
platform support remain separate feature work.

Publication is gated by the Go 1.26/1.27 native matrix on Ubuntu 22.04 and 24.04,
ten independent race/shuffle processes per native job, vet, strict checkptr,
low-GOGC and fuzz, required namespace regressions, README execution, independent
API consumers, Linux/386 and native Windows stub checks, and six-architecture
QEMU ABI/encoding tests. QEMU tests do not claim full SCTP association coverage.
